# Página de produto — GitHub / Vercel

Projeto estático, sem framework e sem dependências externas.

## Estrutura
- `index.html` — estrutura da página
- `css/style.css` — estilos e responsividade
- `js/app.js` — interações
- `assets/images/` — imagens locais de demonstração

## Publicação
Suba a pasta inteira para um repositório GitHub. Na Vercel, importe o repositório como projeto estático, sem build.

## Personalização
Substitua as imagens em `assets/images/` pelas fotos autorizadas do produto e altere marca, textos e checkout no HTML/JS.
